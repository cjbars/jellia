# Jellia

Нативный музыкальный клиент [Jellyfin](https://jellyfin.org) для macOS. SwiftUI, без Electron
и без веб-вью: библиотека, плеер и поиск — обычное приложение macOS.

## Возможности

- библиотека: артисты, альбомы, плейлисты и избранное с обложками;
- воспроизведение через AVFoundation с отчётами о прогрессе на сервер — позиция и история
  синхронизируются с другими клиентами Jellyfin;
- интеграция с Now Playing: обложка и управление в Пункте управления, на медиаклавишах и в Динамическом острове;
- радио (Instant Mix) от трека, альбома, артиста или плейлиста;
- поиск по трекам, альбомам, артистам и плейлистам;
- избранное с переключением прямо из списков;
- кэш обложек с настраиваемым размером; учётные данные хранятся в Связке ключей macOS.

## Требования

- macOS 26 или новее;
- сервер Jellyfin (см. таблицу ниже);
- для сборки из исходников — инструменты командной строки Xcode с SDK macOS 26.

## Поддерживаемые версии сервера

Одна сборка работает со всеми поддерживаемыми версиями: версия сервера определяется при подключении
и видна в Настройках.

| Версия Jellyfin | Статус |
| --- | --- |
| `12.0` | проверяется на разработке |
| `10.11` | поддерживается |
| ниже `10.11` | не проверялась, приложение предупредит об этом |

Эндпоинты, которые использует Jellia, в `10.11` и `12.0` совпадают: пути, параметры запросов
и схемы ответов одинаковы, так что отдельная сборка под версию отличалась бы нулём. Когда появится
ломающее изменение, оно уйдёт в слой совместимости внутри клиента, а не в отдельную сборку.

## Установка

Готовый образ — на странице [релизов](../../releases): скачайте `Jellia-<версия>.dmg`
и перетащите приложение в «Программы».

Сборки не подписаны сертификатом Apple Developer ID, поэтому при первом запуске macOS покажет
предупреждение. Снимите карантин любым из способов:

```bash
xattr -dr com.apple.quarantine /Applications/Jellia.app
```

или откройте приложение через контекстное меню → «Открыть» и подтвердите запуск.

При первом запуске введите адрес сервера, имя пользователя и пароль. macOS спросит разрешение
на доступ к локальной сети, если сервер стоит дома, — без него приложение не сможет подключиться.

## Сборка из исходников

Swift Package Manager и проект Xcode не используются: сборка идёт напрямую `swiftc` из `Makefile`.

```bash
make check   # typecheck + тесты
make build   # build/Jellia.app
make run     # собрать и запустить
make install # установить в /Applications
make dmg     # build/Jellia-<версия>.dmg
```

Версия и номер сборки переопределяются: `make build VERSION=0.1.6 BUILD_NUMBER=42`.
Универсальный бинарник собирается так: `make dmg ARCHS="arm64 x86_64"`.
Сборка обязана проходить со `-swift-version 6 -strict-concurrency=complete -warnings-as-errors`.
